给商家的说明

刷卡机对接还在试用阶段，还没对所有店开放。

把刷卡机连上 PolyPOS

PolyPOS 把金额发到银行给的刷卡机，刷完结果自动回来，不用再手输一遍。两边是通过 Linkly Cloud 连起来的。

开始之前

  • 刷卡机要支持 Linkly Cloud，并且通过店里的 Wi-Fi 或网线连着网。可以看 Linkly 支持的刷卡机列表（英文），或者问银行。
  • 请银行给你的刷卡机开通 Linkly Cloud。银行会发邮件，里面有 Linkly Cloud 用户名和密码。
  • 要能用老板账号登录 PolyPOS 后台。

配对（大约 2 分钟）

  1. 打开 PolyPOS 后台，进「刷卡机」。
  2. 填银行邮件里的 Linkly Cloud 用户名和密码。
  3. 在刷卡机上按 FUNC，输入 8880，再按 OK（或 Enter）。屏幕上会出一串数字，就是配对码。 配对码 3 分钟内有效。刷卡机上没有 FUNC 键、或者出来的不一样，请问银行怎么出 Linkly Cloud 配对码。
  4. 把配对码填进 PolyPOS，点「配对」，看到“配对好了”就成了。
  5. 在同一页点「试刷一笔」刷一小笔，再点「退这一笔」，确认都能用。

出问题时

提示“Linkly 没通过”

检查用户名和密码。配对码 3 分钟就换，重新按 FUNC → 8880 → OK 出一个，马上填。

提示“要重新配对”

可能是刷卡机重新出过配对码、Linkly Cloud 密码改过，或者刷卡机配给了别的收银系统。照上面的步骤重新配。

刷卡机断网了

刷卡机要一直连着网。断网的话，刷卡会等一会儿，然后显示“没发出去”，或者“不确定成没成”（见下面）。

显示“不确定成没成”

PolyPOS 连不上 Linkly 的时候，可能不知道这笔有没有刷成功。请看刷卡机屏幕或打出来的单，然后在 PolyPOS 里点「成功了」或「没成功」。

不确定成没成的时候，不要直接再刷一次。先看刷卡机，免得客人被扣两次。

店里断网的时候

如果刷卡机自己还能连上银行（比如用手机网络，请问银行），就直接在刷卡机上单独刷卡，然后在 PolyPOS 里记成「刷卡」。

有问题请发邮件到 info@polypos.au。
